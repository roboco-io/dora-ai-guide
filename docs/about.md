## 변경 명시

요약 과정에서 다음과 같은 변경을 가했습니다.

- 언어: 영어 → 한국어 / 일본어
- 분량: 핵심 논지·수치·프레임워크를 보존한 **중간 깊이 요약**
- 구조: 원문의 개별 문서를 주제별(리포트·역량·인사이트·가이드)로 재배치

원문의 특정 문장을 그대로 인용한 경우가 있으며, 그 외에는 요약·재서술했습니다. 정확한 수치·맥락은 반드시 원문을 확인하세요.
