# 生成AIが開発作業の価値に与える影響

> 発表: 2024年12月 · 著者: Kevin M. Storer · 原文: <https://dora.dev/insights/value-of-development-work/>

## 核心の発見: 逆説

生成AIを多用する開発者は**フロー時間↑、職務満足↑、生産性↑、バーンアウト↓**を報告しました。しかし同時に

- **退屈な作業に費やす時間は変化なし**
- **価値ある作業に費やす時間は減少**

という結果が出ました。AIが「ルーチン業務を速くし、より良い仕事をさせる」という通念と矛盾します。著者は「価値ある仕事に時間を減らしつつウェルビーイングが良くなる」という逆説から、より根本的な問い — **開発者は業務の『価値』をどう判断するのか** — へ移りました。2024年9月、約90分ずつ10名の深層インタビューを実施しました。

## 価値の5つのレンズ

| 次元 | 意味 | AIの予想される影響 |
|---|---|---|
| **実用的(Utilitarian)** | 世界への影響 | **ポジティブ** — 作業速度を高め影響までの時間を短縮 |
| **評判的(Reputational)** | 遂行した仕事への承認 | **両義的** — 実用的価値は高めるが、AIが功績を持ち去り所有権を曖昧にしうる |
| **経済的(Economic)** | 報酬 | **両義的** — 生産性↑で価値↑、しかしスキルのアクセス性↑で希少性↓ |
| **内発的(Intrinsic)** | 学び・達成の内発的価値 | **中立** — 歴史的に技術は教育の規範を変えてきた |
| **快楽的(Hedonistic)** | 楽しさ | **両義的/中立** — 楽しむ作業をAIが代替すればネガティブ、でなければポジティブ |

## 価値を増幅させる5つの戦略

1. **SDLC全体でAI利用を許可する。** 実用的価値を重んじる開発者はAIを明確な価値増幅器と見ました。可能な限り多くの開発タスクに許可しましょう。
2. **AIと共に行う労働を認める。** 評判的価値を重んじる開発者はAIが自分の功績を持ち去るのではと懸念しました。プロンプトエンジニア、チャット指向プログラミングといった新たな労働が存在します。リーダーシップがこの労働を明示的に認めるべきです。
3. **時間ではなく結果に報いる。** 経済的価値を重んじる開発者は両義的な感情を示しました。生産性が報酬につながりつつ、人員・時間の削減懸念を和らげるには、**アウトプットではなく成果**に報いることです。
4. **AIを新スキル学習の機会としてフレーミングする。** 内発的価値を重んじる開発者は一部スキルが無意味になるのではと懸念しました。新技術は「何を知るか」を変えるだけで「知ること」を無意味にしないと強調しましょう。
5. **楽しむタスクでAIを使わない選択を支援する。** 快楽的価値を重んじる開発者にとってAIは楽しみを奪いかねません。AI利用が強制される例はないため、自分でやりたい開発者を支援することが開発の喜びを保ちます。

## 結論

開発者は業務の価値を**実用・評判・経済・内発・快楽**が絡む複雑な網として理解しています。AIの役割が進化し続けるため、この研究を継続的に精緻化する必要があります。
