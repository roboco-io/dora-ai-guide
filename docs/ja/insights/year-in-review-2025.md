# DORA 2025: 1年の振り返り

> 発表: 2026年1月 · 著者: Nathen Harvey · 原文: <https://dora.dev/insights/dora-2025-year-in-review/>

## リサーチ: 「トリロジー」

2025年、DORAは単一の年次レポートではなく**3部作のトリロジー**を発表しました。

1. **Impact of Generative AI in Software Development**（3月）— 2024の発見を引き継ぎ、リーダー・実践者に利益の最大化とリスク緩和の指針を提供。
2. **State of AI-assisted Software Development**（9月）— SDLC全体でのAIの**増幅効果**を確認。AIは処理量を高めるが基盤が堅牢でなければ安定性を犠牲にする。
3. **DORA AI Capabilities Model**（12月）— AIの利益を増幅する**7つのケイパビリティ**の実行ガイド。

他に人間的な側面を扱った**5本のインサイト**を発表しました。

- **AIはチューターであり不正行為ではない** — 学生は教授・TAを補う学習の伴走者として使う
- **ビルダーマインドセットの台頭** — 職種ではなく**意図**に基づくフレームワーク（Founder・Optimizer・Accelerator・Learner）
- **AI導入拡散のための4つの戦略**
- **測定フレームワーク** — 組織に響き行動を促すものを選ぶ
- **正確性だけの問題ではない** — 真の信頼の障壁はスキル低下・雇用代替・悪用

## 世界の中のDORA

CNN・Business Insiderが採用規模を、Newsweekが「利用は高いが信頼が鍵」という緊張を報じました。Financial TimesがDORA指標を扱ったことは、**ソフトウェアデリバリーパフォーマンスが今や取締役会レベルの関心事**であることを確認させました。

## DORAの変化

- **「脱略語化(de-acronymed)」**: DORAが独立した名称に。年次レポート名を「Accelerate State of DevOps」から**「State of AI-assisted Software Development」**へ変更 — DevOpsを超えた拡張を意味する。
- **デリバリー指標が4つ → 5つへ進化**。
- 2025年にdora.devへ**267件の変更**をデプロイ — 稼働日ごとに1件以上の継続的デリバリー。

## 2026年以降

DORAは高パフォーマンスな技術チームを支えるケイパビリティ・条件・実践・指標の研究を続けます。**「より上手くなることを、より上手くなる(getting better at getting better)」**年となりますように。
