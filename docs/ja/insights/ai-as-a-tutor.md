# 家庭教師としてのAI

> 発表: 2025年12月 · 著者: Andrew Harlan, Kenny Ly, Mindy Tsai, Karissa Wong · 原文: <https://dora.dev/insights/ai-as-a-tutor/>

## 核心命題

批判者は学生がAIでカンニングすると懸念しますが、**UC Berkeleyの研究は違う**姿を示します。学生はAIを**課題の代行者ではなく学習パートナー**として使います。8か月の混合手法研究で、電気工学・CS・デザイン・データサイエンスの学生を深層インタビュー・サーベイしました。

> 「AIは先生だ … 膨大な内容やデータベースに既にあるコードの一部を根本から理解するのに最も役立つ。」

## どう使うか

- **概念理解**: 11件すべてのインタビューで参加者がAIを**「チューター」または「先生」**と表現。学生は低次の細部への労力を減らし**概念的思考**により多くの時間を使え、PM/クリエイティブディレクターのようなプロジェクト企画の役割へ進む機会を得ました。
- **スキル開発**: 2025年5月のサーベイ(N=85)で3つの主要機能は**コードの誤り特定・修正、新しいプログラミング概念の説明**（ほか）。以前はオフィスアワー・Stack Overflowに依存しましたが、AIは**アクセス制約なく**低次の問題（構文、トラブルシューティング、ベストプラクティス）を精緻化させます。
- **要約・学習方向**: 教授が講義で参照した論文を要約・評価して**読む論文を素早く選別**し、どの講義を先に見るかなど**学習の順序を管理**します。
- **メタ認知的利用**: 理解していないことを特定し、学習が必要な領域を把握します。

学生は**識別力(discernment)** を強調しました。AIをいつ使うかだけでなく**いつ離れるか**も知っています。

> 「AIを大きなプロジェクトに使うときはコードの流れを必ず理解する。完全に誤っていることが多いから。」

## インサイト

- **継続的アクセス**: AIは24時間オンデマンドのオフィスアワーとして機能し、学業支援を拡張
- **能動的学習支援**: 答えを得るだけでなく**わからないことを明確にし**、学習の優先順位を決める
- **教育的統合**: AIは学習過程の一部になったので、禁止より認定・指導が必要

## DORAの視点

- **継続的学習の拡張**: 学習文化は組織パフォーマンスを予測します。AIに[社内データへのアクセス](/ja/capabilities/ai-accessible-internal-data)を接続すれば、セルフサービス学習と新規メンバーのオンボーディングを加速できます。
- **価値への集中**: 構文の「労苦」を降ろせば、開発者は**ユーザー中心**を強化しプロダクトオーナーのように働く余力が生まれます。
- **チューターとしてのプラットフォーム**: 良質な社内プラットフォームはセルフサービスの「paved road」を提供し、社内文書は技術的実践を解き放ち組織パフォーマンスを増幅します。
- **イノベーションのための安全網**: AI出力を検証・精製する新しいリテラシーは必須のフィードバックループを作ります。**[小さなバッチ](/ja/capabilities/working-in-small-batches)** と **[バージョン管理](/ja/capabilities/version-control)** がその安全網です。

## 結論

2025年の教育の問いは「学生がAIを使うか」ではなく**「どう使うか」**です。学生はAIを**近道ではなくチューターとして**使い、プロンプト・テスト・修正を繰り返します。これは機械的作業から高次の推論・設計へ焦点を移す**新しいリテラシー**です。
